Crie este repositório para build e deploy do front web do app Expo achou-web.

Passos rápidos:

Copie/commit o conteúdo do seu projeto achou-web (arquivos do app) para este repositório.
Verifique package.json tenha o script build:web (ex.: npx expo export --platform web --output-dir dist).
Ative GitHub Pages: Source = GitHub Actions (Settings > Pages).
Faça push para main e verifique o workflow em Actions.
